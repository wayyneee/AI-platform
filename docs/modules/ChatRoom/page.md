# ChatRoom 畫面規格

> 聊天的所有畫面都放在外殼裡（navbar、側邊欄、log 列由 PlatformInfrastructure 提供），所有元件都用共用元件。
> 畫面共通規則（下拉選單、未儲存的修改、儲存回饋、只做桌面）見 conventions.md 第 9 段。

## 1. 畫面清單
| 畫面 | 說明 | 怎麼進入 |
|---|---|---|
| RoomsPage | 左邊聊天室列表，右邊對話 | navbar「聊天」的預設子頁面；側邊欄「聊天室」 |
| CreateRoomDialog | 建立聊天室 | 聊天室列表的「建立聊天室」 |
| RoomSettingsDialog | 聊天室設定，分頁：基本、成員、記憶、摘要 | 對話右上角的設定按鈕 |
| CharactersPage | 角色卡片牆 | 側邊欄「角色」 |
| CharacterDialog | 一個角色的編輯視窗 | 角色卡片牆的「新增角色」或點角色卡片；對話中錯誤提示的「開啟角色卡」 |
| TemplatesPage | 角色模板卡片牆 | 側邊欄「角色模板」 |
| TemplateDialog | 一個模板的編輯視窗 | 模板卡片牆的「新增模板」或點模板卡片 |
| PersonasPage | 人設卡片牆 | 側邊欄「人設」 |
| PersonaDialog | 一個人設的編輯視窗 | 人設卡片牆的「新增人設」或點人設卡片 |
| KnowledgeBooksPage | 知識書卡片牆 | 側邊欄「知識書」 |
| KnowledgeBookDialog | 一本知識書的編輯視窗 | 知識書卡片牆的「新增知識書」或點知識書卡片 |
| AiOrganizeDialog | 知識書的 AI 整理，疊在知識書視窗上 | 知識書視窗的「AI 整理」 |
| MemoryDialog | 一份記憶（角色、聊天室或全域）的完整清單與編輯 | MemorySummary 的「管理記憶」：角色視窗、聊天室設定的記憶分頁、聊天設定 |
| ChatSettingsPage | 記憶模型、知識書整理模型、全域記憶 | 側邊欄「聊天設定」 |

- 網址：`#/chat/rooms`、`#/chat/rooms/<聊天室>`（重新整理後停在同一個聊天室）、`#/chat/characters`、`#/chat/templates`、`#/chat/personas`、`#/chat/books`、`#/chat/settings`。
- navbar 顯示「聊天」，放左邊第一個，所以打開平台就進入聊天室頁。

## 2. 畫面內容

### 每一頁都有
- **NoModelNotice**：平台還沒有任何 LLM 模型時，內容區最上方顯示「還沒有可用的模型，請先到平台設定新增 API key 和模型」和「前往平台設定」按鈕。
- **頁首橫幅**：聊天室頁以外的每一頁，使用 PlatformInfrastructure 共用元件的頁首，本模組提供文字和看板角色圖。

### RoomsPage
**版面**：左邊固定寬度的聊天室列表，右邊是對話（RoomHeader → MessageList → Composer）。

**元件**：
- **RoomList**：最上方「建立聊天室」按鈕；每列顯示成員頭像（疊在一起）、名稱、最後一則訊息的開頭、時間；最近聊過的排最上面，目前的聊天室標示選中。
  - 進入聊天室頁、網址沒有指定聊天室 → 自動打開最近聊過的聊天室。
  - 點聊天室 → 右邊換成它的對話，網址跟著改。
  - 聊天設定還沒選記憶模型 → 「建立聊天室」不能按，下方提示「請先到聊天設定選擇記憶模型」和前往按鈕。
- **RoomHeader**：聊天室名稱、發言方式標籤（自然／輪流／手動）、MemberBar、設定按鈕。
  - 按設定按鈕 → 開啟 RoomSettingsDialog。
- **MemberBar**：依成員順序顯示角色和人設的頭像；靜音的角色頭像反灰並加靜音圖示；正在說話的角色頭像有動態外框。
  - 點角色頭像 → 小選單「讓他說話」「靜音／取消靜音」，立即生效，不需要儲存。
- **MessageList**：
  - **角色訊息**（靠左）：頭像和名字；思考內容在回覆上方，標「思考過程」，預設收起；回覆內容串流時逐字出現；搜尋來源在回覆下方，「來源 N」點開看列表；底部顯示時間、token（輸入／輸出）、花費、「複製」。
    - 被中止的訊息標「已中止」，保留已產生的部分。
    - 角色已刪除：名字加刪除線並標「角色已刪除」，頭像改成預設頭像。
    - **最後一則角色訊息**另外有「重新生成」和版本切換（‹ 2/3 ›）；切換後對話以選中的版本為準。其他角色訊息只顯示選中的版本。
  - **自己的訊息**（靠右）：人設的頭像和名字、附件（圖片顯示縮圖，PDF、文字檔顯示檔名標籤）、時間、「複製」。人設已刪除時比照角色，標「人設已刪除」。
    - **最後一則自己的訊息**，在還沒有角色完整說完前有「修改」→ 在原處編輯，按「重送」或「取消」。角色正在說話時按「修改」，正在說的那則先中止；重送時拿掉被中止的回覆。
  - **灰色小字**：「XXX 已退出聊天室」；記憶更新（例如「聊天室記憶已更新（新增 1 條）」「米婭記住了一件事」），點一下展開看是哪一條；要求記住但聊天室沒開全域記憶時，顯示「這個聊天室沒有開全域記憶」。
  - **錯誤**：
    - 角色放不下固定的部分 → 紅色提示「XXX 的模型放不下設定的記憶和知識書，請到角色卡調整」和「開啟角色卡」按鈕。
    - 模型上限未知的角色被供應商拒絕 → 錯誤之外加上「這個模型的上限未知，可能是每次送出上限設太大，請到角色卡調小」和「開啟角色卡」按鈕。
    - 其他錯誤（供應商錯誤等）→ 顯示在那位角色的訊息位置，用共用的錯誤訊息格式。
    - 按「開啟角色卡」→ 換到角色頁並開啟那個角色的 CharacterDialog。
- **Composer**：
  - 上方狀態列：回覆中顯示「米婭正在回覆…・接下來：老闆娘」；自動模式顯示「自動聊天中 2/3」。
  - 人設選單：只列這個聊天室的人設，預設上次在這個聊天室用的人設。
  - 輸入框：打 `@` → 跳出聊天室的角色可以選。Enter 送出，Shift+Enter 換行。
  - 附件按鈕：圖片、PDF、文字檔；聊天室裡沒有任何角色看得到時反灰，滑過去顯示原因。
  - 「自動聊 N 輪」按鈕（N 為聊天室設定的輪數）→ 開始自動模式；使用者打字或按停止時結束。
  - 送出按鈕：角色說話時變成「停止」→ 正在說的標「已中止」，排隊的取消。
  - 不能發言時，輸入區換成提示和前往按鈕：聊天室裡沒有人設（「請到聊天室設定加入人設」）、記憶模型失效（「記憶模型失效，請到聊天設定重新選擇」）。

**狀態**：
| 狀態 | 什麼時候 | 畫面怎麼顯示 |
|---|---|---|
| 載入中 | 進入頁面、換聊天室 | 列表或對話區顯示讀取中 |
| 沒有聊天室 | 還沒有建立任何聊天室 | 列表只有「建立聊天室」；對話區顯示空狀態插圖、「還沒有聊天室」和「建立聊天室」按鈕 |
| 發生錯誤 | 讀取列表或對話失敗 | 該區顯示「載入失敗」和「重試」按鈕，並顯示錯誤 |
| 回覆中 | 角色正在說話或排隊中（切頁面、重新整理後回來也一樣） | 串流顯示、Composer 狀態列、「停止」按鈕 |

### CreateRoomDialog
**版面**：頂部圖 → 表單 → 底部「建立」按鈕。

**元件**：
- **表單**：名稱（必填）；角色（可多選，至少一個）；人設（可多選，至少一個，預設勾選「使用者」）；全域記憶開關，旁邊小字「建立後不能修改」；聊天室情境（選填）；聊天室記憶大小（拉條 5,000～30,000，預設 10,000）；摘要大小（拉條 2,000～50,000，預設 8,000）。
  - 還沒有任何角色 → 角色欄位改成提示「還沒有角色」和「去建立角色」按鈕。
  - 按建立 → 必填沒填的欄位紅框；成功後關閉視窗並打開新的聊天室。
  - 按 X 或 Esc → 有未儲存的修改時先詢問。

### RoomSettingsDialog
**版面**：分頁「基本」「成員」「記憶」「摘要」→ 分頁內容 → 底部儲存列。每個分頁各自儲存；有未儲存的修改時切換分頁先詢問。

**元件**：
- **基本**：名稱、情境、發言方式（自然／輪流／手動）、自動模式輪數（1～10）；全域記憶只顯示「已開啟」或「未開啟」，旁邊小字「建立後不能修改」。
- **成員**：成員列表（頭像、名字、角色或人設標籤），可以拖曳調整順序（輪流時用這個順序）；角色另外有健談度拉條（0～100%）和靜音開關；每列有「移出」。上方「加入角色」「加入人設」。
  - 按移出 → 確認視窗；儲存後聊天室出現「XXX 已退出聊天室」，以前的發言保留。
- **記憶**：聊天室記憶大小（拉條）、MemorySummary。
- **摘要**：摘要大小（拉條）、摘要內容（可以修改）；還沒有摘要時顯示「還沒有摘要，對話變長時會自動產生」。

### CharactersPage、TemplatesPage、PersonasPage、KnowledgeBooksPage
**版面**：頁首橫幅 → 卡片牆（EntityCardWall）。

**元件**：
- **卡片**：第一張是「新增」卡；其他卡片內容：
  - 角色：頭像、名字、模型名稱。
  - 模板：模板名稱、模型名稱。
  - 人設：頭像、名字；「使用者」排第一，標「你本人」。
  - 知識書：書名、條目數、約 N token。
  - 模型失效時卡片標「模型失效」。
- 點卡片 → 開啟那一筆的編輯視窗；儲存只存這一筆。要改另一筆，先關掉目前的視窗。
- **知識書搜尋**（只有 KnowledgeBooksPage）：卡片牆上方有搜尋框，輸入時只留下書名符合的卡片；「新增」卡一直顯示。

**狀態**（四頁共用）：
| 狀態 | 什麼時候 | 畫面怎麼顯示 |
|---|---|---|
| 載入中 | 進入頁面 | 卡片牆顯示讀取中，頁首照常 |
| 沒有資料 | 一筆都沒有（人設不會發生） | 空狀態「還沒有角色／模板／知識書」和「新增」按鈕 |
| 沒有符合的 | 知識書搜尋後沒有結果 | 卡片牆只剩「新增」卡，旁邊顯示「沒有符合的知識書」和「清除搜尋」 |
| 發生錯誤 | 讀取失敗 | 「載入失敗」和「重試」按鈕，並顯示錯誤 |

### CharacterDialog
**版面**：大視窗。左邊是分段目錄（基本、模型、知識書、記憶、送出上限），點了跳到那一段；右邊是可以上下捲動的表單。底部固定 ContextBudgetBar 和「刪除」「儲存」。

**元件**：
- **基本**：頭像（AvatarUpload）；名稱、描述（必填）；個性、說話方式、情境、對話範例、開場白（選填）。
  - 新增角色時最上方有「套用模板」選單 → 把模板的模型、參數、提示詞各格複製進來；已經填了內容時先確認會覆蓋。
- **模型**：ModelPicker。
- **知識書**：只列出已經掛上的知識書，每本顯示書名、條目數、約 N token（常駐約 N）和移除按鈕；沒掛任何一本時顯示「還沒有掛知識書」。
  - 按「＋ 掛上知識書」→ 跳出可以搜尋的清單，只列還沒掛的知識書；點一本就掛上並關閉清單。
  - 還沒有任何知識書時，清單顯示「還沒有知識書」和「去建立知識書」（換到知識書頁）。
  - 按移除 → 直接拿掉（還沒儲存，按儲存才生效）。
- **記憶**：角色記憶開關（模型不支援工具時反灰並寫原因）、記憶大小（拉條）、MemorySummary。
- **送出上限**：每次送出上限拉條，旁邊提示「上限越大，每次回覆越貴」。
- **ContextBudgetBar**：分顏色的橫條，顯示提示詞、常駐知識、記憶、摘要、聊天原文、留給回覆各佔多少，以及剩下幾 %；滑過各段顯示約多少 token。固定的部分放不下時整條變紅並寫原因。摘要依角色在的聊天室中最大的那份估算。
- **刪除**（已儲存的角色才有）→ 確認視窗（危險操作）「角色會退出它在的所有聊天室，角色記憶一併刪除」。
- 按 X 或 Esc → 有未儲存的修改時先詢問。

### TemplateDialog
**元件**：模板名稱（必填）、ModelPicker、提示詞各格（描述、個性、說話方式、情境、對話範例、開場白，都選填）；底部「刪除」「儲存」。
- 刪除 → 確認視窗「已經用這個模板建立的角色不受影響」。

### PersonaDialog
**元件**：頭像（AvatarUpload）、名稱（必填）、描述；底部「刪除」「儲存」。
- 「使用者」人設沒有刪除按鈕。
- 刪除 → 確認視窗（危險操作）「人設會退出它在的所有聊天室」。

### KnowledgeBookDialog
**版面**：大視窗。上方書名與總 token 數、「AI 整理」按鈕 → 左邊條目列表、右邊編輯選中的條目 → 底部「刪除」「儲存」。

**元件**：
- **條目列表**：每列顯示標題、常駐或觸發標籤、約 N token；最上方「新增條目」。
- **條目編輯**：標題、常駐／關鍵字觸發、關鍵字（觸發時才出現，可以輸入多個）、內容、約 N token、刪除條目。
- **刪除書** → 確認視窗（危險操作）「有 N 個角色掛著這本書，刪除後會從這些角色身上拿掉」。
- 聊天設定沒選知識書整理模型 → 按「AI 整理」改為提示「請先到聊天設定選擇知識書整理模型」和前往按鈕。

### AiOrganizeDialog
**元件**：
- 模式分頁：「貼上文字切成條目」「下指令修改」；文字框；「開始整理」。
- 整理中顯示讀取中；完成後預覽結果，新增、修改、刪除的條目分別標示。
- 按「套用」→ 關閉視窗，結果放進正在編輯的知識書（還沒儲存，回到知識書視窗按儲存才存）。

### MemoryDialog
**版面**：大視窗。標題（例如「雷恩的記憶」「聊天室記憶・夜城偵探社」「全域記憶」）→ 工具列 → 條目清單（在視窗裡捲動）→ 底部「新增條目」「儲存」。

**元件**：
- **工具列**：搜尋（比對內容）；篩選：記在哪個聊天室（角色、全域記憶才有）、重要度、只看鎖定；排序：最後提到（預設，新的在上）、重要度；右邊顯示「顯示 12／186 條」和用量條。
- **條目**：一行一條，顯示重要度（1～5）、內容、最後提到的時間、記在哪個聊天室、鎖定、刪除。
  - 點內容 → 在原處編輯。
  - 按「新增條目」→ 清單最上方多一條空白條目，游標停在內容。
  - 改重要度、鎖定、刪除 → 先記在畫面上，按儲存才存。
- **儲存**：只存這份記憶，和外面的畫面分開；儲存後用量和外面的 MemorySummary 跟著更新。
- 按 X 或 Esc → 有未儲存的修改時先詢問。

**狀態**：
| 狀態 | 什麼時候 | 畫面怎麼顯示 |
|---|---|---|
| 載入中 | 開啟視窗 | 清單顯示讀取中 |
| 沒有記憶 | 一條都沒有 | 空狀態「還沒有記憶」和「新增條目」 |
| 沒有符合的 | 搜尋或篩選後沒有結果 | 「沒有符合的記憶」和「清除篩選」 |
| 發生錯誤 | 讀取失敗 | 「載入失敗」和「重試」，並顯示錯誤 |

### ChatSettingsPage
**版面**：頁首橫幅 → 記憶區塊 → 知識書區塊 → 儲存列。

**元件**：
- **記憶**：記憶模型（旁邊小字「也負責對話壓縮」）、整理間隔（新訊息累積幾則就整理，預設 20）、全域記憶大小（拉條）、MemorySummary（全域記憶）。
- **知識書**：知識書整理模型。
- 選的模型失效 → 選單紅框並標「模型失效」。

**狀態**：
| 狀態 | 什麼時候 | 畫面怎麼顯示 |
|---|---|---|
| 載入中 | 進入頁面 | 內容區顯示讀取中，頁首照常 |
| 發生錯誤 | 讀取失敗 | 「載入失敗」和「重試」按鈕，並顯示錯誤 |

## 3. 共用元件
（本模組內多個畫面共用）

- **ModelPicker**（TemplateDialog、CharacterDialog）：可以搜尋的 LLM 模型選單，選項提示小字為能力摘要；下方顯示 context 上限、輸出上限（不知道寫「未知」）和各項能力。
  - 參數依能力顯示：「支援」可以調；「未知」寫「未知」、不能調，小字「送出時用供應商預設」；「不支援」反灰並寫原因。
  - 輸出長度用拉條，範圍照平台給的上下限。
  - 模型失效 → 選單紅框並標「模型失效，請重新選擇」。
- **MemorySummary**（CharacterDialog、RoomSettingsDialog、ChatSettingsPage）：一行摘要，顯示條數、用量條「約 8,900／10,000 token」和「管理記憶」按鈕。記憶可能有好幾百條，所以清單不放在這裡。
  - 按「管理記憶」→ 開啟 MemoryDialog（疊在原本的視窗上）。
  - 記憶大小的拉條留在原畫面，和原畫面一起儲存；條目的修改在 MemoryDialog 裡儲存。
- **AvatarUpload**（CharacterDialog、PersonaDialog）：顯示頭像，點擊上傳圖片；沒有上傳時顯示預設頭像。
- **EntityCardWall**（四個卡片牆）：「新增」卡加資料卡片的格狀排列。

## 5. 驗收條件

### 聊天室與對話
- [ ] 打開平台進入聊天室頁，自動打開最近聊過的聊天室；換聊天室時網址跟著改，重新整理後停在同一個聊天室
- [ ] 沒選記憶模型時「建立聊天室」不能按並提示前往聊天設定
- [ ] 建立聊天室時名稱、角色、人設沒填不能建立；建立後打開新的聊天室
- [ ] 平台沒有 LLM 模型時，聊天的每一頁上方出現提示和前往按鈕
- [ ] 角色回覆逐字出現；思考內容預設收起；搜尋來源可以點開；每則訊息有時間、token、花費和複製
- [ ] 只有最後一則角色訊息有重新生成和版本切換
- [ ] 只有最後一則自己的訊息、在還沒有角色說完前有「修改」
- [ ] 按停止時，正在說的標「已中止」，排隊的不再說
- [ ] 角色說話時切到別的頁面再回來，回覆接著顯示
- [ ] 點成員頭像可以讓他說話、靜音；靜音的頭像反灰
- [ ] 聊天室裡沒有角色看得到圖片時，附件按鈕反灰並說明原因
- [ ] 沒有人設、記憶模型失效時，輸入區換成提示和前往按鈕
- [ ] 角色放不下固定的部分時，出現提示和「開啟角色卡」，按了打開那個角色的編輯視窗
- [ ] 記憶更新時出現灰色小字，點了看得到是哪一條
- [ ] 聊天室設定可以移出成員，之後出現「XXX 已退出聊天室」；全域記憶開關不能改

### 卡片牆與編輯視窗
- [ ] 點卡片打開那一筆的編輯視窗；有未儲存的修改時關閉先詢問
- [ ] 角色的名稱或描述沒填時不能儲存
- [ ] 新增角色時套用模板，模板的值帶入；已填內容時先確認
- [ ] 模型能力是「未知」的參數不能調並寫「未知」；「不支援」反灰並寫原因；模型不支援工具時角色記憶開關反灰並寫原因
- [ ] 空間分配橫條各部分加總等於每次送出上限；固定的部分放不下時變紅
- [ ] 「使用者」人設排第一、沒有刪除按鈕
- [ ] 刪除知識書時確認視窗列出掛著它的角色數量
- [ ] 知識書頁輸入搜尋，只留下書名符合的卡片；沒有結果時顯示「沒有符合的知識書」
- [ ] 角色卡只列出已經掛上的知識書；按「＋ 掛上知識書」的清單只列還沒掛的書，可以搜尋，點了就掛上
- [ ] AI 整理的結果先預覽，按套用後才放進編輯中的書，按儲存才存；沒選整理模型時提示前往聊天設定
- [ ] 模型失效的模板、角色，卡片和選單都標「模型失效」

### 記憶
- [ ] 角色視窗、聊天室設定、聊天設定只顯示記憶的條數和用量，按「管理記憶」打開那一份記憶
- [ ] 記憶視窗可以搜尋、依聊天室、重要度、鎖定篩選，依最後提到、重要度排序
- [ ] 有好幾百條記憶時，視窗高度固定、清單在視窗裡捲動
- [ ] 記憶視窗按儲存只存記憶；外面的畫面沒有因此變成「未儲存」
