# PlatformInfrastructure 畫面規格

> 本模組的畫面包含三部分：外殼（AppShell）、共用元件（SharedComponents）、「平台設定」的子頁面（Page）。
> demo 的每個畫面都包含完整外殼，所有元件都用共用元件；外殼和共用元件的外觀以這份 demo 為準。
> 畫面共通規則（下拉選單、未儲存的修改、儲存回饋、只做桌面）見 conventions.md 第 9 段。

## 1. 畫面清單
| 畫面 | 說明 | 怎麼進入 |
|---|---|---|
| BasicSettings | 選擇主題、語言 | 點 navbar「平台設定」後的預設子頁面；側邊欄「基礎設定」 |
| ApiSettings | 管理 API key 與模型 | 側邊欄「API 串接」 |
| UsageStats | 依 API key 查看用量與花費 | 側邊欄「花費統計」 |
| AddModelDialog | 新增模型的小視窗 | ApiSettings 模型分頁中，各類型區塊的「新增模型」按鈕 |

- 網址：`#/settings/basic`、`#/settings/api`、`#/settings/usage`。navbar 顯示「平台設定」，放最右邊。

## 2. 畫面內容

### 外殼（每個畫面都有）
**版面**：上方 navbar（最左側 logo，功能模組靠左，「平台設定」靠右）；中間為側邊欄與內容區；最下方為 log 列；整個外殼有背景圖。

**元件**：
- **Navbar**：點模組切換到它的第一個子頁面；目前所在的模組標示選中；logo 不能點。
- **Sidebar**：列出目前模組的子頁面，目前的標示選中；子頁面 2 個以上才顯示。
- **LogBar**：
  - 收合時只顯示最新一筆的時間、等級、模組、做了什麼；沒有 log 時顯示「目前沒有 log」。
  - 點一下往上展開（最高到畫面一半，可捲動），上方用分頁篩選：全部、正確、警告、錯誤。
  - 每筆顯示：時間（`MM-DD HH:mm:ss`）、等級、模組、做了什麼；有值才顯示狀態、耗時、用量、key 名稱；有錯誤時顯示白話說明和代碼，點開看訊息和細節。
  - 新的 log 即時出現。
- **內容區錯誤畫面**：頁面畫面出錯時，內容區顯示「這個頁面發生錯誤」和「重新整理」按鈕。

### BasicSettings
**版面**：頁首橫幅與標題 → 設定表單 → 儲存列。

**元件**：
- **主題、語言選單**：不需要搜尋，沒有「-- 請選擇 --」；進入時帶入目前的設定。
  - 改選項 → 有未儲存的修改。
  - 按儲存 → 小字顯示「已儲存，即將重新整理套用」，1.5 秒後重新整理頁面。

### ApiSettings
**版面**：頁首橫幅與標題 → 分頁「API key」「模型」（預設 API key）→ 分頁內容 → 儲存列（每個分頁共用一個）。

**元件**：
- **ApiKeyPanel**：上方「新增 API key」按鈕，下方是 key 列表，每列：供應商、名稱、key、刪除。
  - 已儲存的 key：供應商只顯示文字；名稱可以改；key 是密碼框，內容空白、提示文字顯示遮罩值，輸入新值代表換 key。
  - 新增的列：加在最上方；供應商為可搜尋的下拉選單（只列需要 key 的供應商）；名稱、key 必填。
  - 刪除新列 → 直接移除；刪除已儲存的 key → 確認視窗（危險操作）列出選用它的模型數量，確認後刪除並提示。
  - 按儲存 → 先檢查必填，不符合的列紅框、不送出；再依序新增、修改；成功的照存，失敗的列保留紅框和輸入內容，儲存列顯示「部分儲存失敗」。
  - 沒有任何 key 時顯示空狀態「還沒有 API key」和「新增 API key」按鈕。
- **ModelPanel**：由上往下四個區塊：LLM、圖片、影片、語音；每個區塊的標題列有類型名稱、模型數量、「新增模型」按鈕。
  - 區塊沒有模型時顯示一行小字「還沒有<類型>模型」。
  - 按儲存 → 把改選 key 的模型存起來；key 為「-- 請選擇 --」的列紅框、不送出。
- **ModelRow**：顯示名稱（下方小字為供應商的模型名稱）、供應商標籤、連線、價格、「測試」「刪除」。
  - 連線：雲端模型是 key 下拉選單（只列同供應商的 key）；Forge 顯示位址，不能改。該供應商沒有任何 key 時改為提示「請先到 API key 分頁新增 <供應商> 的 key」。
  - 價格：LLM 為「輸入 $x／輸出 $y（每 100 萬 token）」，有每次搜尋價格時加上「・搜尋 $z／次」；其他依單位，例如「$x／張」「$x／秒」「$x／100 萬字」；沒有價格時顯示「未設定價格」；Forge 顯示「本機執行，不計費」。
  - key 為空時紅框：被刪除時顯示「key 已被刪除，請重新選擇 key」，自己選回未選時顯示「請選擇 key」；「測試」不能按。
  - 按測試 → 用這列目前的設定（含還沒儲存的 key）測試，成功提示「測試成功：<顯示名稱>」，失敗顯示錯誤。
  - 按刪除 → 確認視窗（危險操作）提醒其他模組正在使用的設定會失效，確認後刪除並提示。
- **切換分頁**：有未儲存的修改時先詢問，確認後捨棄修改並切換。

### AddModelDialog
**版面**：頂部圖與類型標籤 → 四步表單 → 底部「測試」「儲存」按鈕，測試結果小字在按鈕左邊。

**元件**：四步由上往下，前一步完成後下一步才能操作：
1. **供應商**：可搜尋的下拉選單，只列支援這個類型的供應商。
2. **連線**：需要 key 的供應商選已儲存的 key（沒有時提示「請先到 API key 分頁新增 key」）；Forge 填位址（提示文字 `http://127.0.0.1:7860`）並按「偵測」。
3. **模型**：選好 key 或按偵測後列出偵測結果，偵測中顯示讀取中；每個選項的提示小字為能力摘要（LLM 例如「context 128K・圖片・思考・工具」，只列支援的項目）；選好後顯示模型資訊卡：
   - LLM：說明，以及七項能力（context window 上限、輸出上限、傳圖片、傳檔案、網頁搜尋、思考、調用工具），每項顯示「支援」「不支援」或「未知」；「未知」用警告樣式，卡片下方小字「標示未知的項目，供應商沒有提供資料」。
   - 其他類型：說明、可輸入與輸出的類型（有資料才顯示）。
4. **名稱與價格**：顯示名稱預設帶入模型的顯示名稱；價格欄位依類型（LLM 輸入、輸出兩欄，網頁搜尋不是「不支援」時多一欄「每次搜尋價格」，OpenRouter 不顯示這欄（直接用它回報的金額）；Forge 不顯示價格欄，改為小字「本機執行，不計費」）；自動帶入的價格旁邊標示「已自動帶入」，可以修改；下方小字「沒填價格時只統計用量，不計算花費」。

- 換供應商 → 清空後面所有步驟；換 key 或位址 → 清空模型並重新偵測；選回「-- 請選擇 --」→ 清空它後面的步驟。
- 按測試 → 成功顯示綠色「測試成功」，失敗顯示紅色「測試失敗」和錯誤。測試成功後才能儲存。
- 按儲存 → 成功後直接關閉視窗（不詢問），提示「已新增 <顯示名稱>」，模型列表重新載入。
- 按 X 或 Esc → 有未儲存的修改時先詢問；沒有時直接關閉。點視窗外的背景不會關閉。

### UsageStats
**版面**：頁首橫幅與標題 → 篩選列 → 估算提示 → 兩張長條圖 → 用量摘要。

**元件**：
- **篩選列**：key 選單（顯示「名稱（供應商）」，包含已刪除的 key 並標示「已刪除」，預設第一個，沒有「-- 請選擇 --」）；時間單位分頁：每小時、每天、每週、每月（預設每天）。選到已刪除的 key 時，右邊出現「刪除紀錄」按鈕（危險操作，要確認）。
- **估算提示**：篩選列下方一行一般提示「花費是依模型價格估算的參考值，實際金額以各供應商的帳單為準」，一直顯示。
- **長條圖**：花費圖（美元）和 Token 圖（輸入、輸出疊成一根；沒有 token 用量時不顯示）。X 軸：每小時 `HH:00`、每天 `MM/DD`、每週為週一的 `MM/DD`、每月 `YYYY/MM`。滑鼠移到長條上顯示該格的時間、花費、token，以及有值的搜尋次數、圖片張數、影片秒數、語音字數。花費包含網頁搜尋的花費。
- **沒有價格的提示**：整段都算不出花費時，花費圖改為「這組 key 用到的模型沒有設定價格，無法計算花費，只顯示用量」；部分沒有價格時，上方提示「部分用量沒有設定價格，花費只計算有價格的部分」，有未計價用量的格子加小標記。
- **用量摘要**：一定顯示總花費、輸入 token、輸出 token；有值才顯示搜尋次數、圖片張數、影片秒數、語音字數。遇到沒有價格的情況時加上同樣的提示。

**狀態**（設定的子頁面共用）：
| 狀態 | 什麼時候 | 畫面怎麼顯示 |
|---|---|---|
| 載入中 | 進入子頁面；花費統計換 key 或時間單位 | 內容區顯示讀取中，頁首照常 |
| 發生錯誤 | 進入時查詢失敗 | 空狀態「載入失敗」和「重試」按鈕，並顯示錯誤 |
| 沒有用量 | 選的 key 這段期間沒有用量 | 圖表區顯示空狀態「這段期間沒有用量」 |
| 沒有任何紀錄 | 沒有任何 key 也沒有用量紀錄 | 篩選列和圖表區改為空狀態「還沒有任何用量紀錄」 |

## 3. 共用元件
（SharedComponents 提供給全平台，各模組用它們組畫面）

- **基本元件**：按鈕（主要、次要、危險；儲存中會轉圈並擋住重複點擊）、輸入框（一般、密碼、數字；格式錯誤時紅框）、下拉選單（可搜尋，依畫面共通規則；搜尋時不顯示「-- 請選擇 --」）、開關、分頁標籤。
- **視窗**：
  - 彈出視窗：有標題和 X；可以在關閉前先確認；點背景不關閉；可以疊加（例如視窗裡再開確認視窗），Esc 只作用在最上面那一個。
  - 確認視窗：標題、說明、「取消」「確認」；危險操作的確認按鈕用危險樣式，焦點預設停在「取消」。
  - 換頁時外殼會關閉所有視窗。
- **回饋**：
  - 提示訊息：右上角，最多同時 5 則；成功、一般 3 秒後消失，警告 5 秒後消失。
  - 錯誤訊息：第一行為白話說明，第二行為「模組／介面（代碼：…）」；不會自動消失，要按 X。
  - 讀取中、空狀態（預設插圖＋文字＋選填的按鈕）、長時間任務的等待與進度（排隊中、處理中、有百分比時顯示進度條、完成、失敗與原因）。

## 4. 使用的介面
| 介面 | 來源模組 | 用途 |
|---|---|---|
| getSettings、updateSettings、listSettingOptions | ThemeAndLanguage | 主題與語言 |
| registerTextTable、getText、getAssetUrl | ThemeAndLanguage | 文字與素材 |
| addApiKey、listApiKeys、updateApiKey、deleteApiKey | ModelRegistry | API key |
| listProviders、detectModels、testModel、addModel、listModels、updateModelKey、deleteModel | ModelRegistry | 模型 |
| getUsageStats、deleteUsage | UsageAndCost | 花費統計 |
| listLogs、subscribeLogs、writeLog | SystemLog | log 列、記錄前端錯誤 |
| useLeaveGuard | AppShell | 有未儲存的修改時攔下離開 |
| useSharedComponents、showModal、showConfirm、showToast、showError | SharedComponents | 元件、視窗、回饋 |

## 5. 驗收條件

### 外殼
- [ ] 打開平台進入「平台設定」的第一個子頁面，navbar 最左側有 logo、外殼有背景圖、「平台設定」在最右邊（手動）
- [ ] 用側邊欄切換子頁面，網址跟著改；重新整理後停在同一頁；不存在的網址導回首頁（手動）
- [ ] 有未儲存的修改時，點 navbar、側邊欄、瀏覽器上一頁都先詢問；重新整理時出現瀏覽器的離開提示（手動）
- [ ] 新增模型視窗有修改時按瀏覽器上一頁，確認離開後視窗一起關閉（手動）
- [ ] 後端出錯時 log 列即時出現；展開後可以依等級篩選，點開看得到訊息和細節（手動）
- [ ] 頁面畫面出錯時，只有內容區顯示錯誤，navbar 和 log 列正常，切換頁面後恢復（手動）
- [ ] 設定中的主題不存在時，以 default 正常顯示，log 出現警告（手動）

### 共用元件
- [ ] 彈出視窗點背景不關閉；沒有修改時按 X 或 Esc 直接關閉；有修改時先詢問，Esc 只關掉確認視窗，連按兩次 X 只出現一個確認視窗（手動）
- [ ] 刪除確認視窗的焦點停在「取消」，按 Esc 不會刪除（手動）
- [ ] 成功提示約 3 秒後消失；同時最多 5 則（手動）
- [ ] 錯誤訊息第一行是白話說明、第二行是模組、介面、代碼，按 X 才關閉（手動）
- [ ] 可搜尋的選單只列出符合的選項，↑↓、Enter、Esc 可以操作；視窗內的選單按 Esc 只收合選單（手動）
- [ ] 儲存時按鈕轉圈、不能再按（手動）
- [ ] （MediaCreation 串接後）任務進度依狀態正確顯示：排隊中、處理中（有／沒有百分比）、完成、失敗（手動）

### 設定頁
- [ ] 改主題並儲存，顯示「已儲存，即將重新整理套用」後重新整理（手動）
- [ ] 新增 key 列名稱留空就儲存，該列紅框且沒有送出；填好儲存後顯示遮罩值；只改名稱時 key 不變（手動）
- [ ] 刪除被模型選用的 key，確認視窗列出模型數量；刪除後那些模型紅框並提示，選 key 儲存後紅框消失（手動）
- [ ] 有未儲存的修改時切換 API key／模型分頁會詢問；改回原樣後不詢問、儲存按鈕不能按（手動）
- [ ] 新增模型：選供應商和 key 後出現偵測結果和能力提示；選 LLM 後資訊卡列出七項能力，「未知」為警告樣式；網頁搜尋不是「不支援」時出現每次搜尋價格欄；測試前不能儲存；測試成功後換模型要重新測試（手動）
- [ ] Forge 沒有啟動時按偵測，提示啟動 Forge（手動）
- [ ] 花費統計一直顯示「花費是估算」的提示；切換時間單位，格數為 24、30、12、12；沒填價格時出現對應提示；刪除已刪除 key 的紀錄後，它從選單消失（手動）
- [ ] 主題、語言、花費統計的 key 選單沒有「-- 請選擇 --」；新增模型時把供應商選回未選，後面的步驟全部清空（手動）
- [ ] 平台開著時關掉後端，按儲存或重新查詢，錯誤訊息為「無法連線到平台，請確認平台是否還在執行」（手動）
